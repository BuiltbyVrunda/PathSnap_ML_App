# Member 2 results archive

Copies of the outputs of the real training/testing runs, renamed so each file says what it is. Originals stay where the scripts wrote them (`reports/model-experiments/{comparison,extra}`, `artifacts/models/`); nothing here was regenerated or edited.

Provenance: the runs were executed on a local Windows laptop (CPU, Python 3.13, scikit-learn 1.7.2, LightGBM 4.7, CatBoost 1.2, Optuna) by the scripts named in the *Produced by* column. The notebook `notebooks/member2_training_and_testing.ipynb` loads these saved models/results and re-scores the student_test trips with the saved models.

Model binaries (`*.joblib`) are not copied here; they stay in `artifacts/models/` and `reports/model-experiments/{comparison,extra/comparison}/models/`.
